# CCNA Fast Track - 11: IPv6

> Goal: Understand why IPv6 exists, how addresses are structured, and how devices communicate using IPv6.

---

# Why Was IPv6 Created?

IPv4 has about **4.3 billion** addresses.

That sounded like a lot in the 1980s, but today we have:

- Phones
- Laptops
- TVs
- IoT devices
- Cloud servers

IPv4 addresses eventually became scarce.

IPv6 was created to solve this problem.

---

# IPv4 vs IPv6

| IPv4 | IPv6 |
|-------|-------|
| 32-bit | 128-bit |
| Example: 192.168.1.10 | Example: 2001:db8::10 |
| Uses NAT widely | NAT usually not required |
| Uses ARP | Uses NDP (Neighbor Discovery Protocol) |

---

# IPv6 Address Format

IPv6 uses **128 bits**, written as eight groups of four hexadecimal digits.

Example:

```
2001:0db8:0000:0000:0000:abcd:1234:5678
```

Each group is called a **hextet**.

---

# IPv6 Compression Rules

To make addresses easier to read:

### Rule 1: Remove leading zeros

```
0db8

↓

db8
```

---

### Rule 2: Replace one continuous sequence of all-zero groups with `::`

Example:

```
2001:0db8:0000:0000:0000:abcd:1234:5678

↓

2001:db8::abcd:1234:5678
```

**Important:** You can use `::` only **once** in an address.

---

# Types of IPv6 Addresses

## Global Unicast

Public IPv6 address.

Similar to a public IPv4 address.

Usually begins with:

```
2000::/3
```

---

## Link-Local

Automatically assigned to every IPv6 interface.

Range:

```
fe80::/10
```

Used only within the local network.

Routers do not forward link-local addresses.

---

## Loopback

Equivalent to IPv4:

```
127.0.0.1
```

IPv6:

```
::1
```

---

## Unspecified Address

Equivalent to IPv4:

```
0.0.0.0
```

IPv6:

```
::
```

Represents "no address".

---

# Prefix Length

Instead of subnet masks, IPv6 commonly uses prefix lengths.

Example:

```
2001:db8:1::/64
```

A `/64` is the standard subnet size for most IPv6 LANs.

---

# Address Assignment

Devices can obtain IPv6 addresses in two common ways:

### SLAAC (Stateless Address Autoconfiguration)

The router advertises the network prefix.

The client automatically generates the rest of its address.

No DHCP server is required.

---

### DHCPv6

Works similarly to DHCP for IPv4.

Provides:

- IPv6 address
- DNS server
- Other configuration

---

# Neighbor Discovery Protocol (NDP)

IPv6 does **not** use ARP.

Instead, it uses **Neighbor Discovery Protocol (NDP)**.

NDP is responsible for:

- Finding neighbors
- Discovering routers
- Resolving MAC addresses
- Detecting duplicate addresses

---

# ICMPv6

ICMPv6 is much more important than ICMP in IPv4.

It supports:

- NDP
- Router Advertisements
- Router Solicitations
- Error messages

Blocking all ICMPv6 traffic can break IPv6 functionality.

---

# Cisco Configuration

Enable IPv6 routing:

```
ipv6 unicast-routing
```

Assign an IPv6 address:

```
interface g0/0

ipv6 address 2001:db8:1::1/64

no shutdown
```

# Verification Commands

Show IPv6 interfaces:

```
show ipv6 interface brief
```

Show IPv6 routes:

```
show ipv6 route
```

Ping using IPv6:

```
ping 2001:db8:1::2
```

# Common Problems

❌ Incorrect prefix length.

❌ Using `::` more than once.

❌ Forgetting to enable IPv6 routing.

❌ Missing Router Advertisements.

❌ Blocking ICMPv6.

---

# Cybersecurity Relevance

IPv6 introduces new attack surfaces.

Examples:

- Rogue Router Advertisements
- NDP spoofing
- IPv6 tunneling bypasses
- Dual-stack attacks (IPv4 + IPv6)

Many organizations disable IPv6 without fully understanding it, which can lead to misconfigurations.

As a security professional, always check whether IPv6 is enabled during assessments.

# Key Takeaways

✅ IPv6 uses 128-bit addresses.

✅ It was created to solve IPv4 address exhaustion.

✅ Addresses are written in hexadecimal.

✅ `::` compresses one sequence of zero groups.

✅ Link-Local addresses begin with `fe80::`.

✅ NDP replaces ARP.

✅ SLAAC allows automatic address configuration.

✅ ICMPv6 is essential for IPv6 operation.
